# 图片能力与短提示词

先查目标环境实际能力，不从模型名称推断。优先当前已配置的工具，不为每个任务反复问用户选模型。

| 工具能力 | 路线 |
|---|---|
| 图生图、双参考、中文可用 | 图1实拍、图2原主图；一次生成完整图 |
| 仅单参考、中文可用 | 使用现有图像工具将两张原始输入并排成一张参考包，标注图1真实产品／图2旧主图；保持比例与可读尺寸，不裁掉产品和文案。仅输入用，最终仍单图直出；先试一张 |
| 图生图但中文不稳定 | 沿用原版式，减少装饰与多余说明，逐条写精确文案；不能自行删原文。重试仍错则报告能力不足 |
| 仅文生图或读不到参考 | 无法满足实物一致性替换，停止产品生成，说明需要可读参考的工具 |
| 无图片工具 | 完成计划和提示词，明确尚未出图，不用HTML、SVG或合成图替代 |

不要承诺任何弱模型都能完成。可迁移的是协议、短提示词和验收，不是不存在的图片能力。

单参考工具可用本包 `scripts/prepare_reference.py` 制作参考包。原图与实拍的整幅内容都保留，左右不拉伸。向模型说明：“同一输入图中的1号区域是唯一产品来源，2号区域只供文字和版式；输出完整单张广告，不要复制左右对照结构”。若工具还会将宽图压到文字不可读的尺寸，先停止，不能用模糊参考硬做。

## 弱模型默认短模板

一张提示词只处理一张图；把占位内容填完再提交。

> 生成一张完整拼多多主图，比例【比例】。图1是唯一真实产品，图2只供版式和文字参考。  
> 图1的【整组产品和容器】作为一个整体：保留原视角、形状、颜色、孔洞、排列和数量关系，只精修光线与清理外背景，不拆散、不复制。不用图2的旧产品。核对锚点：【最多5个】。  
> 延续图2的【背景、标题位置、主要色块、底栏标签，最多4项】。  
> 必须完整出现这些文字：【引号逐条列出全部目标文字】。正常粗黑体，不拉伸字形；通过字号和留白适配。文字、色块、圆角边缘都清晰。  
> 图片模型一次生成完整产品、背景、文字和版式。无其他文字、旧产品、额外颗粒或虚构包装。输出一张成品，不要拼图。

若用户已选产品一致优先，再加“保留图1的真实容器，不能改成图2的容器”。未确认冲突时先解决，不在提示词伪造授权。

## 常规模型按需补充

- 细化红黄分区、圆角、斜边、标签排列；不给每个字固定宽高。
- 原图散粒多、实拍是整盘：删除所有旧散粒，禁止复制盘内颗粒到前景。
- 允许裁切，不许改变孔洞、厚度、视角；不用透视变形“适配”轮廓。
- 样图用于视觉标准，产品来源永远原片。

## 有限重试

首轮+最多2次定向重试，始终传原始两张图。每次只加强实际失败处：
- 混入旧产品：图2只参考信息块，旧容器及散粒全部删除。
- 新增星形、花形、长条：点名新增物，禁止新增，保留整组原片。
- 重排进高盒：保留图1真实容器；已确认产品优先时舍弃旧高盒。
- 扁宽字形：正常字宽字高，减字号，不能拉伸。
- 错字漏字：单独列该处完整短句，其他文字不删，不本地补字。
- 色块糊：色块、圆角与字一样清晰，无低清截图质感。

仍失败则停止该图，建议补拍或更强图片工具，不默默切换拼接路线。
