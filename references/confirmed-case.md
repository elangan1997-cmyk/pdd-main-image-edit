# 2026-10-15 滤材主图修改确认案例

以下是本次任务的可审阅输入与用户确认结果，只用于理解决策，不作为其他商品的卖点事实。

## A：黑底红黄

- [原主图](../examples/case-a/original.jpg)：高方透明滤盒、进出水流、红黄标题和底栏。
- [新产品原始实拍](../examples/case-a/product.jpg)：矮方玻璃盒中整组混合滤材。
- [用户确认的模型直出](../examples/case-a/approved-output.png)：保留实拍矮方盒，沿用红黄黑与原文。
- 关键取舍：用户先要求轮廓接近原图，随后确认产品一致优先；因此不把颗粒重排进高方盒。
- 文案：好滤材、不浑水、多合一、净水·培菌、精选。
- 用户确认：这个没问题，你多出几张看看。

## 已得到的流程结论

1. 原片整组产品与原主图版式分成两种角色，先放产品参考，再放原主图。
2. 原片与旧轮廓冲突时明确取舍，不同时要求完全矛盾的容器形状。
3. 模型一次生成产品、标题、色块；后期截取旧字放大和拉伸新字的两条路线已被用户否定。
4. 先一张确认，再扩展，最终覆盖14张原主图。成功不等于其他弱模型天然具备同等能力。

## 可复用短提示词（案例A）

生成一张方形拼多多主图。图1是唯一真实产品，图2只供文字与红黄黑版式参考。保留图1完整矮方玻璃盒、视角、全部颗粒排列和颜色，只精修光线、清理外背景。锚点：左上灰环、上方黄环、中部灰色短柱、右侧浅色球。用户已选产品一致优先，不改成图2高方盒。顶部左红白字“好滤材”，右黄黑字“不浑水”；底部左黄红字“多合一”，右红白字“净水·培菌”，右下黄牌竖排红字“精选”。自然粗黑体，不拉伸；文字、圆角色块同样清晰。旧方盒、水流和旧滤材全部删除，不加散粒。图片模型一次出完整成品，不要拼图或额外文字。
